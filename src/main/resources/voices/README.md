# Voice Models Directory

Place your Piper voice model files here with the following naming convention. Each voice requires both an ONNX model file and a JSON configuration file:

- `edon.onnx` and `edon.onnx.json`
- `arta.onnx` and `arta.onnx.json`
- `arben.onnx` and `arben.onnx.json`
- `dren.onnx` and `dren.onnx.json`

**IMPORTANT:** All four voice models with their corresponding JSON config files are required. The application will fail to start if any voice model or config file is missing.
